# ⭐ 관심 매물 (Dataview)

> [!tip] 필터 조건을 바꾸려면 아래 코드 블록의 `WHERE` 줄을 수정하세요.

## 관심도 높은 순 (★3 이상, 제외 매물 숨김)

```dataview
TABLE WITHOUT ID
  link(file.link, 지역) AS "매물",
  보증금 AS "보증금(만)",
  면적_평 AS "평",
  가까운역 + " " + 도보분 + "분" AS "역세권",
  통근분 + "분" AS "통근",
  관심도 AS "★",
  상태 AS "상태"
FROM #매물
WHERE 유형 = "매물" AND 관심도 >= 3 AND 상태 != "제외"
SORT 관심도 DESC, 보증금 ASC
```

## 예산 내 매물 (보증금 ≤ 30000만)

> 예산 상한을 바꾸려면 `보증금 <= 30000` 숫자를 수정하세요.

```dataview
TABLE WITHOUT ID
  link(file.link, 지역) AS "매물",
  건물형태 AS "형태",
  보증금 AS "보증금(만)",
  면적_평 AS "평",
  융자 AS "융자",
  확정일자 AS "확정일자"
FROM #매물
WHERE 유형 = "매물" AND 보증금 <= 30000 AND 상태 != "제외"
SORT 보증금 ASC
```

## ⚠️ 융자 있는 매물 (등기부 주의)

```dataview
TABLE WITHOUT ID
  link(file.link, 지역) AS "매물",
  보증금 AS "보증금(만)",
  융자 AS "융자",
  확정일자 AS "확정일자",
  중개사 AS "중개사"
FROM #매물
WHERE 유형 = "매물" AND 융자 = true
SORT 보증금 ASC
```
