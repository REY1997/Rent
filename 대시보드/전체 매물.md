# 📋 전체 매물 (Dataview)

> [!info] 사용법
> 이 보기는 **Dataview** 플러그인이 필요합니다. (설정 → 커뮤니티 플러그인 → Dataview 설치·활성화)
> 표 헤더를 클릭하면 정렬할 수 있고, 아래 코드 블록을 수정하면 필터/컬럼을 바꿀 수 있습니다.

## 전체 목록 (보증금 낮은 순)

```dataview
TABLE WITHOUT ID
  link(file.link, 지역) AS "매물",
  건물형태 AS "형태",
  보증금 AS "보증금(만)",
  면적_평 AS "평",
  방 + "/" + 욕실 AS "방/욕",
  가까운역 + " " + 도보분 + "분" AS "역세권",
  상태 AS "상태",
  관심도 AS "★"
FROM #매물
WHERE 유형 = "매물"
SORT 보증금 ASC
```

## 지역별 매물 수

```dataview
TABLE WITHOUT ID
  지역 AS "지역",
  length(rows) AS "매물 수",
  round(average(rows.보증금)) AS "평균 보증금(만)"
FROM #매물
WHERE 유형 = "매물"
GROUP BY 지역
SORT length(rows) DESC
```

## 건물형태별

```dataview
TABLE WITHOUT ID
  건물형태 AS "형태",
  length(rows) AS "매물 수",
  round(average(rows.보증금)) AS "평균 보증금(만)"
FROM #매물
WHERE 유형 = "매물"
GROUP BY 건물형태
```
