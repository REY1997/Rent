# 📋 전체 매물 (Dataview)

> [!info] 사용법
> 이 보기는 **Dataview** 플러그인이 필요합니다. (설정 → 커뮤니티 플러그인 → Dataview 설치·활성화)
> 핵심 4축 = **지역(구/동) · 분류 · 보증금 · 역과의 거리**. 아래 코드 블록의 `WHERE`/`SORT`를 바꾸면 필터·정렬을 조정할 수 있습니다.

## 핵심 4축 한눈에 보기

```dataview
TABLE WITHOUT ID
  link(file.link, 구 + " " + 동) AS "지역",
  건물형태 AS "분류",
  보증금 AS "보증금(만)",
  choice(도보분 > 0, 가까운역 + " " + 도보분 + "분", "역정보 미확인") AS "역거리",
  관심도 AS "★",
  상태 AS "상태"
FROM #매물
WHERE 유형 = "매물" AND 상태 != "제외"
SORT 보증금 ASC
```

## 🗺️ 구별로 묶어 보기

```dataview
TABLE WITHOUT ID
  link(file.link, 동 + " · " + choice(단지, 단지, file.name)) AS "매물",
  건물형태 AS "분류",
  보증금 AS "보증금(만)",
  choice(도보분 > 0, 도보분 + "분 (" + 가까운역 + ")", "-") AS "역거리",
  상태 AS "상태"
FROM #매물
WHERE 유형 = "매물" AND 상태 != "제외"
GROUP BY 구
SORT 구 ASC
```

## 🏘️ 동별로 묶어 보기

```dataview
TABLE WITHOUT ID
  link(file.link, choice(단지, 단지, file.name)) AS "매물",
  건물형태 AS "분류",
  보증금 AS "보증금(만)",
  상태 AS "상태"
FROM #매물
WHERE 유형 = "매물" AND 상태 != "제외"
GROUP BY 구 + " " + 동
SORT rows.보증금 ASC
```

## 🏢 분류(건물형태)별로 묶어 보기

```dataview
TABLE WITHOUT ID
  link(file.link, 구 + " " + 동) AS "지역",
  보증금 AS "보증금(만)",
  면적_평 AS "평",
  choice(도보분 > 0, 도보분 + "분", "-") AS "역거리",
  상태 AS "상태"
FROM #매물
WHERE 유형 = "매물" AND 상태 != "제외"
GROUP BY 건물형태
SORT 건물형태 ASC
```

## 🚇 역과 가까운 순 (도보 기준)

```dataview
TABLE WITHOUT ID
  link(file.link, 구 + " " + 동) AS "지역",
  건물형태 AS "분류",
  choice(가까운역, 가까운역 + " " + 노선, "미확인") AS "역/노선",
  도보분 AS "도보(분)",
  보증금 AS "보증금(만)"
FROM #매물
WHERE 유형 = "매물" AND 상태 != "제외" AND 도보분 > 0
SORT 도보분 ASC
```

## 📊 구별 집계

```dataview
TABLE WITHOUT ID
  구 AS "구",
  length(rows) AS "매물 수",
  round(average(rows.보증금)) AS "평균 보증금(만)"
FROM #매물
WHERE 유형 = "매물"
GROUP BY 구
SORT length(rows) DESC
```
