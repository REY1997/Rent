# 🗓️ 방문 일정 (Dataview)

## 방문 예정

```dataview
TABLE WITHOUT ID
  link(file.link, 지역) AS "매물",
  주소 AS "주소",
  중개사 AS "중개사",
  연락처 AS "연락처",
  입주가능일 AS "입주가능일"
FROM #매물
WHERE 유형 = "매물" AND 상태 = "방문예정"
SORT 입주가능일 ASC
```

## 방문 완료 (최근 순)

```dataview
TABLE WITHOUT ID
  link(file.link, 지역) AS "매물",
  방문일 AS "방문일",
  관심도 AS "★",
  상태 AS "상태"
FROM #매물
WHERE 유형 = "매물" AND 상태 = "방문완료"
SORT 방문일 DESC
```

## 입주 가능일 임박 순 (제외 제외)

```dataview
TABLE WITHOUT ID
  link(file.link, 지역) AS "매물",
  입주가능일 AS "입주가능일",
  보증금 AS "보증금(만)",
  상태 AS "상태"
FROM #매물
WHERE 유형 = "매물" AND 입주가능일 != "" AND 상태 != "제외"
SORT 입주가능일 ASC
```
