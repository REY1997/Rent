# 🏠 전세 매물 정리 볼트 (Obsidian)

부동산 전세 매물을 옵시디언으로 정리하고, **필터별로 모아 보며** 정보를 기록하기 위한 볼트입니다.

## 📁 폴더 구조

```
.
├── README.md              ← 이 파일 (사용법)
├── 매물.base              ← Bases 데이터베이스 (필터·정렬 보기)
├── 매물/                   ← 매물 노트 (매물 1개 = 노트 1개)
│   ├── 예시-역삼동-아파트.md
│   ├── 예시-망원동-빌라.md
│   └── 예시-문래동-오피스텔.md
├── 템플릿/
│   └── 매물 템플릿.md      ← 새 매물 만들 때 복사해서 사용
└── 대시보드/               ← Dataview 보기
    ├── 전체 매물.md
    ├── 관심 매물.md
    └── 방문 일정.md
```

## 🚀 시작하기

1. 이 폴더를 옵시디언에서 **볼트로 열기** (Open folder as vault)
2. 필터 보기를 위해 아래 둘 중 원하는 방식을 활성화:
   - **Bases** (내장): 옵시디언 1.9 이상이면 `매물.base` 파일을 더블클릭하면 바로 표/카드로 보입니다. 별도 설치 불필요.
   - **Dataview** (플러그인): 설정 → 커뮤니티 플러그인 → `Dataview` 설치·활성화 → `대시보드/` 노트들이 작동합니다.
3. (편의) 설정 → 코어 플러그인 → **Templates** 켜고, 템플릿 폴더를 `템플릿`으로 지정하면 새 매물 추가가 편해집니다.

## ➕ 새 매물 추가하기

1. `매물/` 폴더에 새 노트 생성
2. `템플릿/매물 템플릿.md` 내용을 복사해 붙여넣기 (또는 Templates 플러그인으로 삽입)
3. 상단 속성(YAML frontmatter) 값을 채우기
4. `태그: 매물` 이 있어야 모든 보기에 자동으로 잡힙니다

## 🔍 필터 보기

> [!important] 핵심 4축 = **지역 · 분류(건물형태) · 보증금 · 역과의 거리(도보분)**
> 매물을 추릴 때 가장 중요한 기준이라, 모든 보기에서 앞쪽 컬럼·그룹·정렬 기준으로 배치했습니다.

### Bases (`매물.base`)
미리 만들어 둔 보기:
- **핵심 4축** — 지역·분류·보증금·역거리만 추려 한눈에
- **지역별** — 지역으로 묶고 보증금순
- **역과 가까운 순** — 도보 시간 짧은 순
- **전체 매물** — 모든 컬럼, 보증금순
- **관심 매물** — ★3 이상, 제외 제외
- **예산 내 (3억 이하)** — `보증금 <= 30000`
- **융자 주의** — 등기부 확인 필요한 매물
- **카드 보기** — 카드 형태

화면에서 직접 필터·정렬·컬럼을 추가/수정할 수 있습니다.

### Dataview (`대시보드/`)
- **전체 매물** — 핵심 4축 보기 + 지역별/분류별 그룹 + 역 가까운 순 + 지역별 집계
- **관심 매물** — 관심도순, 예산 내, 융자 주의
- **방문 일정** — 방문 예정/완료, 입주일 임박순

필터를 바꾸려면 노트 안의 ` ```dataview ` 코드 블록에서 `WHERE` 조건이나 숫자를 수정하면 됩니다.

## 💡 팁

- **보증금은 항상 만원 단위**로 통일해 입력해야 정렬·평균이 정확합니다.
- 검토가 끝난 매물은 지우지 말고 `상태: 제외`로 바꾸면 기록은 남고 보기에서는 숨겨집니다.
- 예시 노트 3개는 구조 참고용입니다. 익숙해지면 지워도 됩니다.

## 🧭 지역 입력 방식

지역은 `구`와 `동`을 **분리해서** 입력합니다.
- `구` 기준으로 묶으면 → "광진구 전체 매물" 비교
- `동` 기준으로 묶으면 → "자양동만" 콕 집어 보기
- 둘 다 Bases/Dataview 보기에서 지원합니다.

## 💭 향후 아이디어 (백로그)

> 아직 구현하지 않은 검토 항목. 필요해지면 추가합니다.

- **우선순위 점수** — 보증금·역거리·면적 등에 가중치를 줘서 매물별 종합 점수(예: 0~100)를 자동 계산하는 컬럼.
  Dataview의 계산식이나 Bases formula로 만들 수 있음. 가중치(무엇을 더 중요하게 볼지)를 먼저 정해야 함.
